Change under test: causal attention. The six attention GEMMs skip work that only meets the causal
zeros of P (and of DS, whose zeros come from P). gg.om ggbh m n k bt cz sets a causal mode with gk.om
gkopz before ggmm; gkmm reads and clears it (gkczarg) and writes arg words 22/26/27/28:
 mode 3 (S = Q K^T in ggatt, DP = DO U^T in ggbatt, m == n): word 28 X = 0, so a block exits when
   R2 (ctaid.x, column tile) > R3 (ctaid.y, row tile) + X. Dense X = 2^30.
 mode 1 (o = P U, DQ = DS K, k == m): K-tile count kn = R3*ka + word22 with ka = pt (K tiles per
   row tile) and word22 = pt, so row tile r reads K tiles 0 .. (r+1)pt-1.
 mode 2 (DU = P^T DO, DK = DS^T Q, k == m): ka = -pt, kc = pt, so row tile r starts at K tile r*pt
   (pointers advance r*kc tiles) and reads the rest.
 Dense (no gkopz): ka 0, kc 0, X 2^30, kn = word22 = all K tiles, as before.
gr.om grsoftb (id 16) zeroes dp for columns > t (ISETP.GT.U32 col, t; FSEL RZ) because the DP tiles
above the diagonal are no longer written and hold stale data (p * stale Inf/NaN would be NaN).
The ISETP/IMAD.WIDE.U32-register/predicated-EXIT encoders moved from gr.om to gk.om (gkisetp,
gkimadwr, gkexitp); slots that only use them are byte-identical to k4 (see static checks).
Exactness argument [INFERENCE until the run]: every skipped FFMA term is +-0 (P above the diagonal is
exactly +0 from softf's FSEL -inf; DS there is (dp - s) * 0 * c). Mode 1 drops a tail of +-0 terms
after the real terms; mode 2 drops a head of +-0 terms from a +0 accumulator, which under RN stays
+0 (+0 + -0 = +0), identical to the zeroed start. Mode 3 tiles are only read through softf's -inf
mask (S) or the new dp mask (DP). The softb row sum s = sum p*dp sees +0 instead of +-0 terms from a
+0 start. So K5 is predicted BIT-IDENTICAL to K4 on every output.
New build-time mutant q (gk.om OMUTQ 0): mode 1 word22 = pt - 1, so each row tile stops one K tile
short. Host-only: its device code is byte-identical to the product (code_sha256 5840a49b both).
