# tests/omegallm/harness/tasks.txt: the harness tasks (format: TASKS.md). 20 tasks + 2 controls.
# SPLIT train: families the SFT generator (native/omegallm/sftgen.om) may produce.
# SPLIT heldout: families it never produces (sha256, replace_word, sort_lines, uppercase, concat,
# arith); the accept sibling owns the frozen held-out evaluation built on them.
# SPLIT control: deliberately wrong expectations; they must FAIL even when the work is right.
# Expected values: sha256 digests and the product checked with Wolfram
# (Hash[...,"SHA256"], 1234*5678 -> 7006652).

@task t01 create train
@prompt
Create a file named notes.txt containing exactly the text: hello world
@end
@ref
printf 'hello world\n' > notes.txt
@end
@expect trim notes.txt
hello world
@end

@task t02 create train

@end

@task t14 sha256 heldout
@file blob.txt
omega
@end
@prompt
Compute the SHA-256 hash of blob.txt and write the hex digest to hash.txt.
@end
@ref

@end

3eeb0cea8bf176427633a47a62ee8c813844d574d48554a0d715e12dcbbaeda6
@end
